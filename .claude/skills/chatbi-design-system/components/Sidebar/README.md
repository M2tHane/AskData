# Sidebar

左侧主导航：品牌名 + 分组导航 + 底部身份说明。

- `groups: [{label, items: [{id, label, icon, count?}]}]`，`active` 为当前项 id，`footer` 放当前团队、角色和安全说明。
- 分组固定为「查数 / 数据 / 治理」。按角色裁剪：员工只看到查数和数据下的“语义与别名”“指标”（个人级）；团队负责人多出“反馈”“查询日志”“评测（只读）”；管理员看到全部。没有权限的入口直接不显示，不做置灰。
- 选中项：`accent-soft` 底 + `accent` 图标。计数只用于需要处理的东西（待处理反馈、待审核申请）。
- 宽度 `sidebar-width`。
