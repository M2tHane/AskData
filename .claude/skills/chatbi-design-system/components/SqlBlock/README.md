# SqlBlock

SQL 代码块：展示、复制、手动编辑后重跑。

- `sql`、`onRun(sql)`（有它才出现「编辑」）、`defaultOpen`（日志等排查场景默认展开）。耗时只在回答头部显示一次，这里不重复。
- 头部固定显示“只读 · 已校验”：只读账号执行、单条 SELECT、通过安全校验。用户编辑后多一个“已手动修改”标记，重跑前同样走校验。
- 关键字 `code-keyword`、字符串 `code-string`、数字 `code-number`、注释 `code-comment`；底色 `surface-sunken`。
- 回答里默认收成一行（▸ SQL · 只读 · 已校验），点开才显示全文和复制、编辑；长行折行显示，不横向裁切。子句只在顶层和子查询里换行，`OVER (… ORDER BY …)`、`IN (…)` 保持在一行。
- 编辑：点「编辑」后文本框与展开的全文同高、随内容长高；只有内容真的改了才显示“已手动修改”。「取消」或 Esc 放弃修改；「重新执行」后结果作为新一轮回答出现，原块回到原 SQL，可照常折叠。重跑沿用原回答的图表配置（列仍在时）。
