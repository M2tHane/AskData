# ResultCard

一轮回答的结果卡：把图表和表格放在同一张卡里，替代分开的 ChartCard + ResultTable。

- 头部左侧：「图表 | 表格」切换（`cb-seg cb-seg-text`）；结果不能出图时只显示表格，不出现切换。
- 头部右侧：图表模式下是图表类型（柱状 / 条形 / 堆叠 / 折线 / 占比 / 散点，按数据可用性给出）和「PNG」；表格模式下是「导出 CSV」「导出 Excel」。
- 表格最多显示 30 行；页脚写明「共 N 行，表格显示前 30 行」，只有表格视图且结果多于 30 行时才说明「导出会重新执行查询获取全部数据（最多 X 行、Y MB）」。导出被上限截断时用 Toast 提示实际行数。页脚不写耗时（回答头部已有）。
- 只有一行且全是数值（如「订单金额合计」）时用大数字展示，不画一行表格，也不显示页脚。
- 列名用图表配置的 `labels`（中文显示名），数值按 `formats` 格式化（金额两位小数、比率显示为百分比、计数取整）；只有真正的数字列右对齐，编号、手机号等数字字符串保持原样。
- 类别名过长或类别多于 12 个时默认画横向条形图；比率与金额同图时比率放右轴，图例标「（右轴）」。
- 数值标签同一系列用同一单位和小数位（不混用「1.2万」和「8,399」），最大值到 10 万才用「万」；刻度步长取 1/2/2.5/5×10ⁿ，上限只多出不到一格；单系列柱子顶上标数值。
- 折线图只在横轴是时间（日期、月份、季度、年）或数值时提供；月初日期显示为「2026-01」。分组超过 5 个时保留合计最大的 4 个，其余并为「其他」。
