# AskData 设计规范

AskData 是面向企业内部的「问数」平台：员工用一句中文提问，系统生成只读 SQL、执行并给出结论、口径和图表。这套设计系统是它的界面升级版，视觉语言照 CC Switch v7：中性灰白为底，黑白做主操作，一抹品牌橙；图表沿用 AskData 原有的配色与画法。

## 内容与语气

- 全中文界面，句子短，不用感叹号和 emoji。按钮动词开头、2–4 个字：「立即同步」「新建数据源」「重新执行」。
- 称呼用户为「你」，系统自称「我」只出现在 AI 的回答里（「我是这样理解的」）。
- 结论先行：回答第一句就给数字（「9 月华东区销售额 ¥4,286 万，比 8 月增长 6.3%」），口径和 SQL 放在后面。
- 状态文字说清楚结果和下一步：「销售分析组 Token 配额已用到 86%。超过 100% 后，新的提问会被拒绝。」
- 数字：千分位、tabular-nums；大数用 K / M / B 缩写，完整值放在悬停提示里；金额带 ¥ 或 $。
- 登录与权限类错误不暴露账号是否存在：「账号或密码不正确」。

## 颜色

- 底色分三层：主区 `bg-app`，侧栏 `bg-sidebar`，下沉区 `bg-subtle`（分段控件轨道、SQL 正文、悬停行）。当前选中项用 `bg-selected`。深色主题下卡片 `bg-card` 比主区亮一档，靠明度分层，不加阴影。
- 文字三级：`text-1` 正文和数字，`text-2` 次要（侧栏未选项、卡片标签），`text-3` 最弱（表头、坐标轴、同步状态）。三者在所有底色上都 ≥4.5:1。
- 主操作黑白：主按钮、用户提问气泡、发送按钮用 `inverse-bg` / `inverse-fg`。
- 品牌橙 `action` 只出现在：标记方块、开关打开、登录页要点勾号。橙色当文字时一律用 `action-text`。
- 复选框不用浏览器原生样式：16px、圆角 4px、`line-control` 描边；勾选和半选是 `inverse-bg` 实底 + `inverse-fg` 细线勾 / 短横（见 `Field`、`PagePermissions`）。
- 图表沿用 AskData 原有配色：`chart-1` 深蓝、`chart-2` 琥珀、`chart-3` 青绿、`chart-4` 橙、`chart-5` 浅蓝，深色主题各有提亮的一套；只画数据（柱、线、饼、图例），不做按钮或链接。单序列只用 `chart-1`，多序列依次取色。
- 图表画法沿用 `charts.tsx`：柱子每个系列最宽 28px、系列间隔 4px，单序列且放得下时柱顶标数值；堆叠柱最宽 48px、块间留 1px 底色缝；折线 2px、圆点 3px；占比图是实心饼图，图例在右侧并写百分比；散点 4.5px、75% 不透明。坐标轴和数值文字 12px（原来是 11px），图例 13px。
- 状态色成对使用：`success` / `warning` / `danger` / `info` 文字配同名 `*-soft` 底；徽标和提示里都要有文字，颜色只是辅助。
- 描边：卡片和分隔线 `border`；按钮和筛选下拉 `border-strong`；文本输入框和复选框 `line-control`（边框是它们唯一的轮廓，≥3:1）。
- 焦点环 `focus`：2px 实线、偏移 2px。CC Switch 原用 `#f97316`，在白底上只有 2.8:1，这里压深到 `#c2410c`。

## 字体

- 不加载网络字体，用系统字体栈 `font-sans`：macOS 上是 SF Pro Text + 苹方，Windows 上是 Segoe UI + 微软雅黑——和 CC Switch 完全一致。等宽用 `font-mono`（SF Mono / Consolas）。
- 字号按角色取用，不自造：`page` 页标题 18/600，`metric` 统计数字 24/600，`section` 卡片标题和 Tab 15/600，`title` 对话结论 16/600，`strong` 按钮与标签 14/500，`body` 正文与表格 13，`caption` 卡片标签与说明 12，`badge` 徽标与侧栏分组名 11/500，`code` SQL 与模型名 12 等宽。
- 所有数字列、统计数字、时间戳加 `font-variant-numeric: tabular-nums`。

## 间距、圆角、尺寸

- 4px 网格：`space-1` 4 … `space-8` 32；统计卡左右用 `space-3-5`（14px）。页面左右 `space-6`，区块之间 `space-3`。
- 圆角三档：`radius-control` 6px（按钮、输入框、侧栏行、徽标），`radius-panel` 10px（卡片、统计卡、分段轨道），`radius-dialog` 14px（对话框、提问输入区）。分段选中块 `radius-seg-item` 7px。
- 控件高度：分段选项 `control-xs` 26，侧栏行与小按钮 `row-sm` 28，默认按钮、输入框、下拉 `control-md` 32，登录页 `control-lg` 40。
- 阴影只给浮层：`shadow-sm` 分段选中块，`shadow-md` 下拉与 Toast，`shadow-lg` 对话框。卡片只有描边，没有阴影。

## 布局

- 外壳：左侧 `Sidebar`（216px，`bg-sidebar`）+ 右侧主区。业务入口（对话、数据源、语义、指标）在上；治理与系统入口（反馈、查询日志、评测、权限、团队、模型、提示词、用量）平铺沉到底部，最后是账号与设置。侧栏导航项后面不带数字。
- 管理页骨架：`PageHeader`（56px）→ 筛选行（左 `Segmented`、右 `Dropdown`）→ `StatCard` 一行 + 「更多指标」→ 图表卡 → 下划线 `Tabs` + `DataTable`。完整示例见 `PageUsage`。
- 对话页：不使用页头，侧栏 / 会话列表 / 对话流三栏到顶；对话流最大宽度 `chat-max-width`。
- 一轮回答的信息层级固定为：**结论 → 图表（可切表格、可换图型）→ 按需展开的口径与 SQL**。思考过程是结论上方一行可折叠的灰字；口径和 SQL 默认收起在结果下方同一行，同一时间只展开一个，右侧是「有用 / 没用 / 复制」。见 `ChatTurn`、`ResultCard`、`ChatStates`。
- 登录页：单页双栏，左表单右示意，见 `LoginPage` 与 `LoginStates`。
- 对话页右侧有可折叠的「可用字段」面板：表下拉 → 字段名 / 类型 / 别名 → 点行看说明（带平台级 / 团队级 / 个人级徽标），字段超过 15 个时分页，只列当前用户可见的表和字段。进入对话或新建会话时默认展开，发出消息后自动收起。
- 新增「我的看板」（`PageDashboard`）：对话回答可以「固定到看板」，看板按原 SQL 定时刷新。新会话用 `ChatEmpty` 给出基于指标和语义的示例问题。
- 每个模块都有一张可交互的整页稿（`Page*`）：Tab 可切换，点按钮会打开对话框，点行会打开抽屉，开关、树形展开、图型切换都能用。
- 表格对齐只有一条规则：所有列（包括数字列）一律左对齐，数字加 `tabular-nums`，操作列放在最右。
- 分页：列表超过 10 条时，在卡片底部出现分页条——左边「共 N 条 · 每页 10 条」，右边上一页 / 页码（超过 7 页时中间用省略号）/ 下一页 / 「跳至 [ ] 页」（回车跳转）。10 条以内不显示分页条。窄栏（如对话页的会话列表）用紧凑版：上一页 · 1 / 3 · 下一页 · 跳至。
- 列表页（数据源、语义、指标、反馈、查询日志、评测记录、团队与成员、提示词）的卡片高度不随行数变化：统一撑到距窗口底边 120px 处，各页卡片底边对齐；内容多时在卡片内部滚动，表头吸顶，分页条贴在卡片底部。
- 语义的三级覆盖：平台（管理员维护，所有人的默认）→ 团队（团队负责人覆盖平台，对本团队生效）→ 我的（员工覆盖团队和平台，只对自己生效）。编辑哪一级由角色决定，页面上不放层级切换。「恢复」回到上一级当前的值，按钮文字写明回到哪一级（「恢复为团队」「恢复为平台」）。
- 通知统一用右下角的小卡片（`Toast`）：保存成功、测试连接、同步开始 / 完成、评测开始 / 完成、导入完成、固定到看板、卡片刷新失败都走它，4 秒自动消失、悬停暂停、最多同时 3 张。需要用户做决定的事（删除、未保存离开）用对话框，不用通知。
- 列表的非正常状态统一四种：首次为空、搜索无结果、加载中（骨架行）、加载失败（说明 + 重试 + 错误编号），见 `ListStates`。
- 可编辑的页面（语义、提示词、权限）有未保存的修改时，切换对象或离开页面先弹「有未保存的修改」：放弃并离开 / 继续编辑 / 保存并离开。
- 宽度：设计基准 1280px。1024–1279px 布局不变，表格靠省略号和换行压缩；1024px 以下侧栏收成 60px 图标栏。不支持手机。
- 列表行的详情用右侧抽屉（`ak-drawer`，440px；树形内容 600px），新建和编辑用居中对话框（`ak-dialog`，520 / 720px），删除一律二次确认。

## 可交互原型

- 这里的预览可以直接操作（Tab、弹窗、抽屉、图表切换等）。整站串起来的版本是 `prototype/askdata-prototype.html`（直接用浏览器打开）——登录后用侧栏在 13 个模块间跳转，Tab、弹窗、抽屉、图表切换、复选框、开关、预览角色和深浅色都能操作；地址后面加 `#logs`、`#usage` 这类模块名可以直接打开对应页面。
- 原型和这里共用同一份 `tokens.json` 与 `components/bundle.css`，两边的样子保持一致。

## 「新增」标记

- 页面稿里带虚线橙框「新增」小标的，是这次重构建议补上、但现有代码里还没有的功能（例如日志的各环节耗时、反馈转评测题、语义的枚举值映射）。实现时可以先只做界面并隐藏入口，等后端接好再打开。
- 「新增」标记只用于设计稿，不要带进产品界面。

## 图标

- 沿用 AskData 现有的 24×24 线性图标（`Icon.tsx` 的 `ICON_PATHS`），1.7px 描边、圆角端点、`currentColor`。导航和按钮里 16px，页头标题旁 22px。
- 补充了 `user`、`settings` 两个路径，风格与现有图标一致。
- 没有 Logo 文件：品牌标记是 22px 的 `action` 方块里一个白色「A」，加「AskData」字样。以后有正式 Logo 时替换 `ak-mark`。

## 从旧样式迁移

- 旧 `tokens.css` 的变量一一对应：`--canvas` → `bg-sidebar`（侧栏）/ `bg-app`（主区），`--surface` → `bg-card`，`--surface-sunken` → `bg-subtle`，`--surface-hover` → `bg-subtle`，`--line` → `border`，`--line-control` → `line-control`，`--ink` → `text-1`，`--ink-muted` → `text-2` 或 `text-3`，`--primary` → `inverse-bg`，`--accent` → `action-text`，`--info` → `info`，`--chart-1` → `chart-1`。
- 字号整体从 14px 降到 13px 正文（CC Switch 同款），表格行高 40px。
- 胶囊式 `cb-tabs` 改为下划线 `Tabs`；需要切视角的地方改用 `Segmented`。
- Toast 和 Callout 去掉 4px 左边框，改为整块浅底。
- 设计稿里的类名前缀是 `ak-`（不要用 `ad-`：广告拦截插件会把 `ad-` 开头的元素整个隐藏），样式全部在 `components/bundle.css`，只读 `tokens.json` 生成的变量；落到代码里时保留项目原有的 `cb-` 前缀。
