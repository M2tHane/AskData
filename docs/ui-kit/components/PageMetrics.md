指标：分「指标」「申请」两个子模块，用下划线 Tab 切换，不再挤在一页。指标子模块是搜索 + 级别筛选（全部 / 平台级 / 团队级 / 个人级）+ 指标表（名称与别名 / 口径 / 级别 / 校验 / 最近校验 / 操作），不做版本管理。申请子模块是待审核 / 已处理切换 + 申请表，通过后团队或个人指标成为平台级；驳回时可以填理由。表格卡片高度固定，撑到距窗口底边 120px 处（与其他列表页底边对齐），行多时卡片内滚动、表头吸顶。编辑指标对话框新增参数与「试跑」，删除改为二次确认。指标表新增「近 30 天引用」列（被提问用到的次数，0 次显示为灰色），可按引用次数排序，方便清理没人用的指标；引用的字段被删除时校验列显示「引用字段已删除」。
