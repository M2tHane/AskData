登录页：单页双栏。左边 5 份是表单列（`bg-app`），右边 7 份是产品示意（`bg-sidebar`）；窄于 880px 时只留表单列。

- 表单列：左上品牌标记 → 居中 340px 宽的表单 → 底部版权与审计声明。标题 `login`（24px/600），副标题 `text-2`。
- 字段：账号（`autocomplete="username"`）、密码（`current-password`，带「显示」切换和大写锁定提示）、「记住账号」复选框、黑色主按钮 `ak-btn-lg ak-btn-block`。账号和密码在同一页，不拆两步，保证密码管理器能自动填充。
- 「忘记密码？」放在密码标签行右侧。后端没有自助重置，点击后在按钮下方展开提示「请联系团队负责人或管理员」，不跳页。
- 错误：一律写「账号或密码不正确」，不暴露账号是否存在；放在主按钮上方的 `Callout` danger，并把焦点移回密码框。请求过于频繁时改用 warning 提示稍后再试。提交中按钮显示「登录中…」并禁用。
- 右侧示意：一句价值主张 + 一张静态的「提问 → 结论 → 图 → SQL」卡片 + 三条信任要点（只读校验、权限隔离、可追溯）。整块 `aria-hidden`，不放可点击元素。
- 以后接入企业 SSO：在账号框下方加「使用企业账号登录」次按钮；输入的账号命中 SSO 域时再显示它，并把密码框置灰而不是隐藏。
