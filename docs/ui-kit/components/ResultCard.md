查询结果卡：一轮回答的主体，放在结论正下方、口径与 SQL 之上。交互和现有 `ResultCard` 一致，只换外观。

- 头部左侧：「图表 / 表格」分段切换（`Segmented`）+ 结果标题；右侧在图表视图下是图型切换（`ak-kinds`，只列出当前数据能画的图）和「PNG」导出，在表格视图下是「导出 CSV」「导出 Excel」。
- 可用图型沿用 `availableKinds()`：柱状图总有；条形图在没有双轴时有；堆叠柱状图需要多系列且都非负；折线图只给时间或数值横轴；占比图只给单指标、2–5 个类别；散点图只给数值横轴。默认图型沿用 `initialKind()`（时间序列默认折线）。
- 配色和画法沿用 AskData 原有的 `charts.tsx`：单序列只用 `chart-1`（深蓝），多序列依次 `chart-1`…`chart-5`；柱子每系列最宽 28px；占比图是实心饼图、图例在右；放得下时柱顶标数值。坐标轴、数值 12px，图例 13px，都比原来大一号。
- 只有一行、全是数值的结果用大数字（`ak-kpis`，28px/600），不显示切换。
- 底部：`共 N 行`；表格只显示前 30 行时补一句「表格显示前 30 行」，到达行数上限时加 warning 徽标「已达行数上限」。
