通知小卡片（Toast）：平台上所有「操作结果」和「后台事件」的提示都用它，统一从窗口右下角弹出。

- 位置与尺寸：距右、下各 20px，宽 340px，最多同时 3 张，新的在下面，超出时最早的一张先消失。
- 结构：左侧 20px 圆形状态图标（success / info / warning / danger，`*-soft` 底 + 同名色图标）→ 标题（13/600）→ 一行说明（12，`text-2`）→ 可选的一个文字动作（「查看」「撤销」）→ 右上角关闭。底部 2px 进度条表示剩余时间。
- 时长：默认 4 秒；鼠标悬停时暂停，移开后重新计时。带动作的通知可以给 6 秒。
- 用在哪：保存成功、测试连接、同步开始 / 完成、标记已处理、转为评测题、固定到看板、评测开始 / 完成、导入完成、卡片刷新失败。
- 不用在哪：需要用户做决定的（删除确认、未保存离开）用对话框；表单字段错误写在字段下方；会持续存在的问题（只读账号、字段变化）用状态徽标。
- 运行时：`window.akToast({tone, title, text, action, goto})`；按钮上写 `data-toast` 即可，数组表示按 `delay` 依次弹出（先「进行中」再「完成」）。
- 无障碍：容器 `role="status"` + `aria-live="polite"`，不抢焦点。
