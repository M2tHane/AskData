数据源（管理员）：统计卡 → 类型分段 + 搜索 → 数据源表。类型列带数据库图标（沿用仓库 `public/datasource-icons`）。行操作按固定槽位排：数据库是「测试 / 编辑 / 同步」，上传文件只有「上传数据」并占「同步」的位置，开关永远在最后一格；导入中的开关照常显示但不可点。「新建数据源」是图标卡片列表（图标 + 名称 + 默认端口），选中后进入连接表单。Excel / CSV 只能通过上传进来：在「新建数据源」里选 Excel / CSV（或在已有上传数据源的行上点「上传数据」），经过「选择文件 → 确认表结构 → 导入」三步，文件写进平台内置库，每个工作表成为一张表；所以列表里上传数据源的名字是数据集名而不是文件名，地址列写它包含几个文件，状态列显示导入中 / 正常。新增「表数」「最近同步」「状态」三列，把只读账号警告、待导入、停用都放进状态列。点「新建数据源」先选类型再填连接表单（新增 TLS 开关）；点名称打开右侧「可见范围」抽屉（团队 Chip + 表 / 字段树，新增「全部展开」「只看自定义」）。同步后发现字段新增、删除或改名时，状态列显示「字段变化 N」，点开右侧抽屉列出每处变化、类型和影响（哪些指标口径失效、哪些语义或权限要跟着改），并给出跳转；处理完点「标记已处理」。测试、同步的结果用右下角通知（`Toast`）反馈。

标着「新增」的是这次重构建议补上的功能，现有代码里还没有；可以先只做界面，后续再接后端。
