语义与别名：左右分栏，两张卡片高度固定，撑到距窗口底边 120px 处（与其他列表页底边对齐），内容多时在卡片内滚动。左边是表列表（每行显示「已设语义 / 字段数」）；右边不放层级切换，编辑哪一级由角色决定：员工改「我的」，团队负责人改「本团队」，管理员改「平台」。三级覆盖：平台是所有人的默认（只有管理员能改）；团队负责人可以覆盖平台，对本团队生效；员工可以覆盖团队和平台，只对自己生效。生效顺序是 我的 → 团队 → 平台。来源列显示当前层级下这个字段的值从哪来：本层改过的显示「我的」或「团队」徽标，并给出「恢复为团队 / 恢复为平台」，即回到上一级当前的值；没改过的显示「沿用团队 / 沿用平台」。本层改过的行左侧有一条橙色细线。字段表：字段（下方小字是类型）/ 别名 / 说明 / 枚举值映射 / 来源；勾选「枚举」后在该字段下展开取值→含义列表，枚举值也按同样的三级覆盖（后端已有 `enum_mapping`）。表头一行放表名、表的别名和说明（标签在输入框左侧），行末注明沿用哪一级。不再有「申请提升」。表列表里，有字段变化的表带「N 处变化」标记。有未保存的修改时切换到别的表，会先弹「有未保存的修改」对话框（放弃并离开 / 继续编辑 / 保存并离开）。保存成功用右下角通知。
