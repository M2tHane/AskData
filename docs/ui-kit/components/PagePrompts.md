提示词：不再显示顶部警示。提示词分 Markdown 和 YAML 两种，编辑器按内容自动识别格式并高亮（Markdown：标题、列表、粗体、行内代码；YAML：键、字符串、数字、注释；两者都高亮 ${变量} 和 <untrusted_data> 数据块），底部状态栏做格式校验（YAML 解析错误会指出行号，并禁用保存）和必需变量检查，「格式化」按钮按各自规则整理缩进。点左侧列表可以切换提示词。左侧「提示词」「历史版本」两张卡都可以折叠（点标题），右侧是编辑器（变量、数据块、标题高亮，底部是必需变量检查）。新增「试一个问题」以及保存后自动跑评测的选项；「查看修改」打开差异对话框。

标着「新增」的是这次重构建议补上的功能，现有代码里还没有；可以先只做界面，后续再接后端。
