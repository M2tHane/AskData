销售额
指标 · 团队级已支付订单金额，不含退款（GMV）
华东 / 华南
语义region 字段；华东 = 上海、江苏、浙江、安徽、福建、江西、山东

口径不对？
点「没用」选「口径不对」，或到「语义与别名」里补充 新增
SQL只读 · 已校验
SELECT DATE_FORMAT(order_date, '%Y-%m') AS month, region, SUM(paid_amount) / 10000 AS sales
FROM dw.fact_orders
WHERE order_date BETWEEN '2026-04-01' AND '2026-09-30'
  AND region IN ('华东', '华南') AND refund_flag = 0
GROUP BY month, region ORDER BY month LIMIT 500
